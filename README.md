# KOC ONE · منصة ORT للإنذار والحصر

مبني على مقترح KOC ONE (محمد عبدالله طاهر · 83784). ثلاثة أجزاء تعمل معًا عبر Supabase:

| الجزء | المجلد | التقنية |
|---|---|---|
| قاعدة البيانات والربط اللحظي | `supabase/` | Supabase (Postgres + RLS + Realtime + Storage + Edge Function) — **مُنشأة ومفعّلة** في مشروع `KOC-ONE` |
| لوحة ORT في مركز 160 | `dashboard/` | Vue 3 + Leaflet (بدون خطوة بناء) — تُنشر على GitHub Pages |
| تطبيق الموظف | `mobile/` | Flutter → APK لأجهزة Android 7+ |

## ما تفعله اللوحة
- **القطاعات › Zones › المباني** مع رسم حدود GPS على الخريطة، أو إدخال الإحداثيات، أو التقاط نقطة من موقعك، وتصنيف المنطقة (غير مصنفة / Zone 2 / 1 / 0) ورسالة تظهر للموظف عند عبور الحدود.
- **إطلاق الإنذار** (الإشارة 1 طوارئ · 2 إخلاء · 3 زوال الخطر · رسالة) لـ: موظف واحد، مبنى، Zone، قطاع، أو جميع القطاعات — يصل لمن هو **داخل الحدود** فقط، ولكل من يدخلها ما دام الإنذار نشطًا. تأكيد ثنائي ووضع تمرين.
- **الحصر اللحظي**: آمن / يحتاج مساعدة / مصاب / محتجز / بدون رد، مع فصيلة الدم والموقع.
- **اتصال صوتي** بالموظف من المتصفح إلى التطبيق (WebRTC).
- **بلاغات 160 مشفرة** مع الصور: تُشفّر على الهاتف ولا يفكّها إلا ORT بعبارة المرور.

## خطوات التشغيل (مرة واحدة)
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتوى هذا المجلد إلى الفرع `main`.
2. في المستودع: **Settings › Pages › Source = GitHub Actions**.
3. يبدأ البناء تلقائيًا (Actions). بعد ~10 دقائق:
   - ملف **KOC-ONE.apk** في صفحة **Releases** (وفي Artifacts).
   - اللوحة على `https://<اسمك>.github.io/<المستودع>/`.
4. ادخل اللوحة بحساب ORT، ثم افتح تبويب **مفتاح التشفير** وأنشئ المفتاح (احفظ عبارة المرور).
5. أنشئ حسابات الموظفين من تبويب **الموظفون**، وسلّمهم البريد وكلمة المرور لتطبيق الهاتف.

> للتجربة المحلية للوحة: `cd dashboard && python3 -m http.server 8080` ثم افتح `http://localhost:8080`.

## ملاحظات تشغيلية
- التطبيق يعمل كخدمة مقدّمة (إشعار دائم «الحماية مفعّلة») ليستقبل الإنذار والهاتف مقفل؛ امنح «الموقع طوال الوقت» والإشعارات وملء الشاشة.
- نغمات الإنذار تُشغّل على مسار **المنبّه** (Alarm) فتُسمع في الوضع الصامت على معظم الأجهزة؛ يختلف السلوك بين الشركات المصنّعة ويُختبر في التجربة.
- الموقع لا يُرسل إلا عند عبور الحدود وأثناء إنذار نشط — لا تتبّع مستمر.
- للمكالمات عبر شبكات الشركة المقيّدة أضف خادم TURN في `dashboard/config.js` و `mobile/lib/config.dart`.
- التطبيق مكمّل للصفارات والنداء العام وشبكة TETRA، لا بديل عنها.
